4. FORMULA NUMERICAL VERIFICATION
--------------------------------------------------------------------------------
Example 1:
- Principal P = $100,000.00
- Annual Interest Rate = 12.0%
- Tenure n = 12 months
- Monthly Rate r = (12.0 / 12) / 100 = 0.01
- (1 + r)^n = 1.01^12 = 1.12682503
- EMI = [100000 * 0.01 * 1.12682503] / [1.12682503 - 1] = 1126.82503 / 0.12682503
  EMI = $8,884.88
- Total Payable = $8,884.88 * 12 = $106,618.55
- Total Interest = $106,618.55 - $100,000.00 = $6,618.55

Example 2:
- Principal P = $500,000.00 (Home Loan)
- Annual Interest Rate = 7.5%
- Tenure n = 240 months (20 years)
- Monthly Rate r = (7.5 / 12) / 100 = 0.00625
- (1 + r)^n = (1.00625)^240 = 4.46081704
- EMI = [500000 * 0.00625 * 4.46081704] / [4.46081704 - 1]
  EMI = $4,027.97
- Total Payable = $4,027.97 * 240 = $966,713.06
- Total Interest = $966,713.06 - $500,000.00 = $466,713.06
