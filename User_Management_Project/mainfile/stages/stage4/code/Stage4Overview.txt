1. OVERVIEW
--------------------------------------------------------------------------------
Stage 4 introduces the PAN & CIBIL Intelligence Module:
- PAN Card Validation: Enforces ^[A-Z]{5}[0-9]{4}[A-Z]{1}$ with exact error message:
  "Invalid PAN format. Please enter a valid PAN."
- Loan Type Validation: Enforces Home Loan, Personal Loan, Education Loan, Vehicle Loan
  with exact error message: "Invalid loan type selected."
- CIBIL Score Generation: Generates random 3-digit score strictly between 600 and 900.
- Interest Rate Calculation Engine: Maps CIBIL score to defined interest rate ranges:
  * Home Loan: 6.5% – 8.5%
  * Personal Loan: 9.0% – 12.0%
  * Education Loan: 4.0% – 6.0%
  * Vehicle Loan: 7.0% – 9.0%
  Exact output string format:
  "For PAN [PAN], with a CIBIL score of [CIBIL], the interest rate for [Loan Type] is [Rate]%."
- Auto-Generation of Credentials:
  * Username: First 3 letters of First Name + First 3 letters of Last Name + Last 4 digits of Mobile.
    (Example: Shivani + Chaudhari + 9876543210 -> ShiCha3210).
  * Password: 8-10 characters containing letters, numbers, and symbols (e.g. @Shiv!123).
  * Email Dispatch of Credentials with subject: "Your Username and Password for Loan Application is".
- Database persistence: `pancard` and `cibil_score` columns on `users` table.
- Seamless transition to loan application after CIBIL check.
