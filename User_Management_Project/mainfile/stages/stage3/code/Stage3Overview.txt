1. OVERVIEW
--------------------------------------------------------------------------------
Stage 3 introduces the Loan Application Management System, seamlessly extending Stages 1 & 2:
- User Side:
  * Regular users can apply for loans through their console menu.
  * Fields: Loan Amount, Loan Type (Personal, Home, Education, Vehicle), Duration (months),
    Annual Income, Purpose.
  * Auto-calculated default interest rate:
    - Personal Loan: 10.5%
    - Home Loan: 7.5%
    - Education Loan: 5.0%
    - Vehicle / Car Loan: 8.0%
  * Positive number validation on amount, duration, and income. Mandatory purpose.
  * Initial status is automatically set to 'Pending'.
  * Real-time viewing of user's submitted loan applications and current statuses.

- Admin Side:
  * Admin Loan Review menu: Lists all loan applications with ID, Applicant Name, Type,
    Amount, Application Date, and Status.
  * View Full Loan Details with applicant profile details (joined from `users` table).
  * Approve Loan: Updates status to 'Approved', logs audit record, and sends approval email.
  * Reject Loan: Requires mandatory rejection reason, updates status to 'Rejected',
    records rejection reason, logs audit record, and sends rejection email.
  * Stage 3 Email Notifications strictly formatted:
    - Approval Subject: "Your Loan Application has been Approved!"
      Body: "Dear [User], your loan application for [loan amount] has been approved. Please check your dashboard for further details."
    - Rejection Subject: "Your Loan Application has been Rejected"
      Body: "Dear [User], we regret to inform you that your loan application has been rejected. Reason: [reason]. Please contact support for more details."
